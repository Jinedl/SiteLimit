# Образцы снимков для тестов распознавания

Каждый файл — снимок из отладки SiteLimit (кнопка «Копировать»), первая строка `# expect: сервис тип [название]`.
Файлы `synthetic_*` составлены по исходному коду приложений, это не снимки с телефона.
Присланные снимки кладутся сюда как `snap_*.txt` — тест ClassifierTest проверит их все.
