# SiteLimit

Android-приложение, которое ограничивает время на отдельных сайтах в **Яндекс Браузере** (обычном, Lite, бета) и в приложении **«Яндекс — с Алисой»** — как StayFocusd на компьютере. Готовые блокировщики (AppBlock, StayFree, BlockSite) Яндекс Браузер не поддерживают, поэтому здесь своя служба специальных возможностей.

## Как работает

- Служба специальных возможностей следит только за браузерами Яндекса: `com.yandex.browser` (+ `.lite`, `.beta`, `.alpha`) и «Яндекс — с Алисой» (`com.yandex.searchapp`, `ru.yandex.searchplugin`).
- Раз в секунду читает адресную строку и добавляет секунду к сайту, если для него задан лимит. Поддомены считаются вместе: лимит на `youtube.com` действует и на `m.youtube.com`.
- Если адресная строка спряталась при прокрутке, сайт считается прежним. Другой адрес в строке сбрасывает текущий сайт.
- При выключенном экране и в других приложениях время не идёт.
- Когда дневной лимит исчерпан — через 1,5 секунды (успеть переключить вкладку) переход на главный экран и окно «Лимит исчерпан». Лимит сбрасывается в полночь.
- Список вкладок, главная Яндекса и экран поиска сайтом не считаются.
- Данные хранятся только на телефоне, в интернет приложение не ходит (разрешения на интернет у него нет).

## Установка APK

1. Откройте на телефоне страницу последней версии: **https://github.com/Jinedl/sitelimit/releases/latest**
2. В разделе *Assets* нажмите на `SiteLimit-X.Y.apk` — файл скачается.
3. Откройте скачанный файл. Если телефон спросит, разрешите браузеру «Установку неизвестных приложений» и вернитесь назад.
4. Нажмите «Установить». Play Защита может предупредить о неизвестном разработчике — «Всё равно установить».

Новые версии ставятся так же, поверх старой: лимиты и статистика сохраняются.

## Включение службы

1. Откройте SiteLimit → кнопка **«Открыть Специальные возможности»**.
2. Найдите **«SiteLimit — лимиты сайтов»** (иногда в разделе «Скачанные приложения» / «Установленные службы») и включите.
3. **Если переключатель серый и пишет «Ограниченная настройка»** (Android 13 и новее, для приложений не из магазина):
   1. Нажмите на серый переключатель один раз и закройте сообщение — без этого нужный пункт меню не появится.
   2. Настройки → Приложения → **SiteLimit**.
   3. Меню **⋮** в правом верхнем углу → **«Разрешить ограниченные настройки»** → подтвердите PIN-кодом или отпечатком.
   4. Вернитесь в Специальные возможности и включите службу.
4. В приложении должно появиться «Служба: включена ✅».

Если служба сама выключается — разрешите SiteLimit работать без ограничений в настройках батареи (Настройки → Приложения → SiteLimit → Батарея → «Без ограничений»).

## Пользование

- Введите сайт (`youtube.com`) и минуты в день → «Добавить». Тот же сайт с другим числом меняет лимит.
- В списке видно «сайт — N из M мин». Долгое нажатие — удалить.

## Отладка адресной строки

Если «Сейчас в браузере» показывает не тот сайт или «—»:

1. Включите галочку «Сохранять снимок окна браузера».
2. Откройте сайт в Яндекс Браузере, подождите 3–5 секунд, вернитесь в SiteLimit.
3. «Показать снимок» → «Копировать» и пришлите текст. В снимке есть все элементы окна браузера (кроме содержимого страницы) с их `id` и текстом.
4. Если видно, у какого `id` в тексте адрес сайта, впишите этот `id` в поле «свой id адресной строки» → «Сохранить». Тогда служба будет брать адрес именно из него.

## Сборка и подпись

Сборка идёт только в GitHub Actions (`.github/workflows/build.yml`) при каждом пуше в `main`. Если версия (`versionName` в `app/build.gradle.kts`) новая, подписанный APK публикуется в GitHub Release `vX.Y`.

APK подписывается **постоянным** ключом — иначе новые версии не установятся поверх старых. Ключ создаётся один раз workflow `keygen.yml`, шифруется (AES-256, PBKDF2) паролем из секрета `SIGNING_PASSWORD` и хранится в репозитории как `signing/release.p12.enc`. Без пароля файл бесполезен, поэтому пароль должен быть длинным и случайным.

Один раз нужно:

1. Придумать пароль не короче 16 символов (лучше сгенерировать в менеджере паролей) и **сохранить его** — посмотреть секрет потом нельзя.
2. Repository → Settings → Secrets and variables → Actions → New repository secret: имя `SIGNING_PASSWORD`, значение — пароль.
3. Actions → «Создать ключ подписи (один раз)» → Run workflow. Он создаст ключ и сам запустит сборку.

Не удаляйте `signing/release.p12.enc` и не меняйте секрет: с новым ключом обновить установленное приложение не получится, придётся удалять его вместе с данными.
